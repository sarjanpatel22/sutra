# From-Zero Gap Audit — 2026-06-15

Four parallel sub-agents audited the whole codebase (Voice, Memory/RAG,
Core/router/skills/agent/MCP, GUI/watch/vision/cli/tests/docs). Findings were
**verified against the real code before acting** — at least one ("budget race") was
overstated and is *not* a real bug in single-threaded asyncio. This file records what
was fixed and what was consciously deferred, so the deferred items aren't lost.

## Fixed this pass (committed)

**Recall / memory**
- LLM reranker over the bi-encoder's top-N (`friday/memory/rerank.py`, wired into
  `recall_index`). Measured live, end-to-end: hit@1 **80 → 100%**, hit@3 95 → 100%.
  Off the hot path by default (`RECALL_RERANK=1`); the memory GUI uses it regardless.
- **Qdrant falsehood removed.** Qdrant was dropped (`SUTRA_PHASES.md`) but the seed
  still wrote "memory uses Qdrant for vectors" — so recall told Sarjan something false.
  Fixed the seed, the live graph (deleted 2 Qdrant edges, added the true nomic fact),
  the eval probe, `CLAUDE.md`, and `.env.example`.
- **`looks_low_value` over-match.** The blunt `"firefox"/"youtube" in text` rule
  silently dropped real facts that merely *name* a browser (e.g. the TryHackMe /
  Firefox-cookie story). Tightened to require a telemetry *shape*; added regression tests.

**Core safety (router / agent / mcp / skills)**
- **H1 — paid-tier leak (`router.py`).** A tool-turn fallback escalated to billed
  Claude without checking `ROUTER_ALLOW_PAID`. Added `allow_paid()` and gated it — the
  $0 guarantee now holds even on a fully rate-limited tool turn.
- **H2 — `close_window` voice gate bypass (`agent.py`).** It's `auto_confirm=False`
  (can lose unsaved work) yet sat in `_VOICE_AUTO_APPROVE`. Removed; the deterministic
  "close X" command path is unaffected.
- **MCP bridge double-init race (`bridge.py`).** Added an `asyncio.Lock` around
  check-and-connect / close (covers both H3 and M7).
- **CANONICAL_GATED blind spot (`skills/audit.py`).** `act_on_screen` carries no
  mutation verb in its name, so nothing locked its gate. Added `act_on_screen` +
  `type_into` to the CI invariant.
- **L2 — synthesis temperature (`agent.py`).** Final voice answer now uses 0.3 (was
  0.7 default) so it reports tool results faithfully.

**GUI / vision / rag / docs**
- `ocr_available()` now checks `DISPLAY` (mirrors `screen_available`) — honest
  "no display" instead of a misleading "couldn't read the screen" headless.
- RAG `add()` de-dups re-ingested chunks (same text no longer piles up).
- New `tests/test_graphview.py` covers `/api/graph`, `/api/recall`, `/api/facts`
  (the recall endpoint was previously untested).
- `cli.py` deprecated `get_event_loop()` → `get_running_loop()`.
- `.env.example`: documented `ROUTER_ALLOW_PAID`, `SUTRA_AUTONOMOUS`, `RECALL_RERANK*`,
  and the dropped-Qdrant note. Fixed the stale "not fixed" `AUDIO_INPUT_DEVICE` doc note.

## Deferred — with reason (NOT done)

| Gap | Why deferred |
|-----|--------------|
| **Split `cli.py` (719) / `agent.py` (570) / `monitor.py` (421)** into sub-modules | Large refactor with high regression surface; quality not correctness. Do it attended, with `sutra` smoke-tested after. |
| **H4 — budget `_save()` "race" + blocking I/O** | The race is **not real** in single-threaded asyncio (`record()` has no `await`, so it's atomic). Only the tiny JSON write is sync, sub-ms. The proposed async refactor ripples to every caller for ~no benefit. |
| **M1(core) — subagent tool whitelist is schema-only** | Real defense-in-depth gap, but the leak is read-only local skills (`read_file`, `system_info`); no active exploit. Enforcing it threads an allowed-set through the tool-exec core — worth an attended pass. |
| **M4(core) — `router.py` `load_dotenv()` second secret path** | Purity, not a vuln (`.env` fallback is supported by design). Removing it risks breaking scripts/tests that import the router standalone. |
| **M8(core) — `monitor.py` import-time side effects** (`logging.basicConfig`, `mkdir`) | The `basicConfig` anti-pattern is real, but moving import-time behavior is moderate-risk and best done attended. |
| **M6(core) — `decide()` unused `history` param** | Removing it is an API change for ~no gain; it's a documented future hook. |
| **M2/M3(core) — sync file/subprocess I/O in async** | Sub-ms in practice (64 KB read cap; `Popen` returns fast). Style, low impact. |
| **M2(GUI) — `changed(0,0)` cooldown edge** | "Fixing" it fights the *intentional* "failed capture → err toward looking" contract (which `test_screen` locks). No API cost results today. |
| **M4(GUI) — vision-model constant duplicated 5×** | Real maintainability smell (and `allow_paid` is now a 2nd small dup in `router`/`autoroute`); fold into one `constants.py` in a focused cleanup. |
| L1/L3/L7 (core), L1/L2/L3 (GUI), web_search error leak, etc. | Low severity; batch into a later polish pass. |
